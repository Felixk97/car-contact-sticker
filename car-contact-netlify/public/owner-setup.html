🔔 Vehicle Owner Setup

This version keeps your notification topic private — it lives only in Netlify's environment variables, never in the page the visitor sees.

One-time setup

  1. Install the free ntfy app on your phone.
  2. Pick a long, random topic name (don't reuse this example) and subscribe to it in the app.
  3. In your Netlify site's dashboard, go to Site settings → Environment variables and add NTFY_TOPIC set to your topic name.
  4. Deploy the site (see README.md for the exact steps).
  5. Open your deployed URL, submit a test alert, and confirm it reaches your phone.

Note: because the topic is now set as an environment variable rather than written into the HTML, you will not see it by inspecting the page source — this is intentional.
